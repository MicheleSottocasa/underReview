# Contributing

Thanks for helping make ReviewDesk better. The best way to contribute is with feedback: bug reports, ideas and questions.

## Report a bug or suggest a feature

Open an [issue](https://github.com/MicheleSottocasa/underReview/issues). First search the existing issues; if yours is already there, add a comment or a 👍 instead of opening a new one.

A good issue has:

- **One topic.** Open separate issues for separate problems or ideas.
- **What happened and what you expected**, for bugs, with the steps to reproduce.
- **Your setup:** the ReviewDesk version, the macOS version and, for AI features, the provider (Claude Code, Codex or Ollama).
- **A screenshot** for anything visible in the UI.

Leave out anything private: tokens, private repository names, code or PR contents you can't share.

## Start a discussion

For an open question, an idea that isn't ready to be an issue yet, or to share how you use ReviewDesk, start a [discussion](https://github.com/MicheleSottocasa/underReview/discussions). Ideas that take shape there become issues.

## Code

The source is public for transparency, but the [license](LICENSE) doesn't allow modified versions, so pull requests aren't accepted. Describe the change in an issue instead.

## Security

Don't report security problems in a public issue. Use [private vulnerability reporting](https://github.com/MicheleSottocasa/underReview/security/advisories/new) instead.
